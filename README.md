# Discord Music Bot

Музыкальный бот для одного Discord-сервера. Играет треки, альбомы и плейлисты с YouTube, YouTube Music, Spotify, SoundCloud, Apple Music, Яндекс Музыки и VK Музыки. Управляется слэш-командами, кнопками мини-плеера в чате и веб-панелью.

## Как устроено

```
Discord ──► bot (Node.js, discord.js)  ──► Lavalink (Java) ──► YouTube / SoundCloud / Яндекс / VK
              │  мини-плеер, команды            ├─ youtube-plugin + yt-cipher (подписи YouTube)
              │  веб-панель :8090                ├─ LavaSrc (Spotify, Apple Music, Яндекс, VK)
              │  data/settings.json              │    └─ spotify-tokener (токены Spotify без аккаунта)
              ▼                                  └─ LavaLyrics (тексты песен)
         вебхук мониторинга
```

Всё запускается через `docker compose` на VPS. Звук идёт из Lavalink, бот только командует.

**Spotify и Apple Music** не отдают звук сторонним программам. Бот берёт с них название и код ISRC, находит тот же трек на YouTube Music и играет его оттуда.

## Возможности

- `/play` с подсказками: начинаешь печатать, и Discord показывает найденные треки (с площадки по умолчанию или выбранной в параметре `площадка`). Принимает ссылки на треки, альбомы, плейлисты и исполнителей.
- Мини-плеер в чате: обложка, прогресс, кнопки ⏮ ⏯ ⏭ 🔀 ⏹, повтор очереди 🔁 и трека 🔂, автоплей ♾️, громкость 🔉 🔊, очередь 📜, текст песни 🎤 и меню «Перейти к треку».
- Автоплей: когда очередь кончается, бот добавляет похожие треки (микс YouTube, рекомендации Яндекса и VK).
- Синхронный текст песни: строка подсвечивается по ходу трека, на следующем треке текст переключается сам.
- Режим 24/7: бот сидит в канале и возвращается туда после перезапуска.
- Веб-панель: плеер с очередью, все настройки, статус площадок, проверка источников и логи.
- Мониторинг: уведомления в Discord-канал через вебхук, если упал аудиосервер или YouTube попросил вход.
- Автообновление плагинов Lavalink раз в час. Обновление ставится, только когда музыка не играет.

### Команды

| Команда | Что делает |
|---|---|
| `/play запрос [площадка] [следующим]` | Включить или добавить в очередь |
| `/pause` | Пауза / продолжить |
| `/skip [сколько]`, `/previous` | Следующий / предыдущий трек |
| `/stop` | Остановить и очистить очередь (в 24/7 бот остаётся в канале) |
| `/leave` | Выйти из канала (выключает 24/7) |
| `/queue [страница]` | Очередь |
| `/nowplaying` | Отправить мини-плеер вниз чата |
| `/shuffle`, `/loop режим` | Перемешать, повтор |
| `/volume`, `/seek 1:30` | Громкость, перемотка |
| `/remove`, `/move`, `/jump`, `/clear` | Правка очереди |
| `/autoplay [включить]` | Автоплей |
| `/lyrics` | Текст песни |
| `/247 [включить]` | Режим 24/7 в текущем голосовом канале |
| `/panel` | Как открыть веб-панель |

Управлять плеером может любой, кто сидит в одном голосовом канале с ботом.

## Установка

### 1. Discord-приложение

1. https://discord.com/developers/applications → **New Application**.
2. **Bot** → **Reset Token** → скопируй токен (это `DISCORD_TOKEN`). Привилегированные интенты не нужны.
3. **OAuth2 → URL Generator**: scopes `bot` и `applications.commands`; права `View Channels`, `Send Messages`, `Embed Links`, `Read Message History`, `Connect`, `Speak`. Открой ссылку и добавь бота на сервер.
4. ID сервера: Discord → Настройки → Расширенные → Режим разработчика; затем ПКМ по серверу → **Копировать ID** (это `DISCORD_GUILD_ID`).

### 2. Сервер

```bash
git clone git@github.com:<you>/discord-music-bot.git /opt/discord-music-bot
cd /opt/discord-music-bot
bash scripts/setup.sh        # создаст .env с паролями
nano .env                    # впиши DISCORD_TOKEN и DISCORD_GUILD_ID
bash scripts/setup.sh        # запустит всё
```

Нужны Docker с плагином compose. Памяти уходит около 1.5–2 ГБ: Lavalink до 1.2 ГБ, остальные сервисы по 100–400 МБ.

### 3. YouTube

Сервер в дата-центре, и YouTube отвечает таким IP «Sign in to confirm you're not a bot». Поэтому бот входит через **запасной** Google-аккаунт. Основной не используй: аккаунт могут ограничить.

```bash
bash scripts/youtube-login.sh
```

Скрипт покажет код. Открой https://www.google.com/device, войди запасным аккаунтом и введи код. Токен сохранится в `.env` сам. Если YouTube снова начнёт просить вход, бот пришлёт уведомление. Тогда запусти скрипт ещё раз.

### 4. Яндекс Музыка и VK Музыка (по желанию)

Обе площадки ограничены по региону, а сервер стоит в Финляндии.

**Яндекс Музыка** работает с подпиской Плюс или через прокси в России/СНГ.

1. Открой https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d и войди.
2. Из адреса, на который тебя перекинет, скопируй значение `access_token=…` (страница быстро уходит, можно включить замедление сети в DevTools).
3. В `.env`: `YANDEX_MUSIC_TOKEN=…`. Если подписки нет, заполни ещё `YANDEX_PROXY_URL` (и при необходимости логин и пароль).

**VK Музыка** вне России работает только через российский прокси. Токен лучше брать с отдельного аккаунта.

1. Открой https://oauth.vk.com/authorize?client_id=6463690&scope=1073737727&redirect_uri=https://oauth.vk.com/blank.html&display=page&response_type=token&revoke=1 и войди.
2. Из адреса скопируй `access_token=…`.
3. В `.env`: `VK_MUSIC_TOKEN=…` и `VK_PROXY_URL=http://user:pass@host:port` (или отдельно `VK_PROXY_USERNAME` / `VK_PROXY_PASSWORD`).

После правки `.env`:

```bash
docker compose up -d --force-recreate lavalink
```

Источник включится сам, как только появится токен. Проверить можно в панели: **Статус → Проверить площадки**.

**Spotify** и **Apple Music** ключей не требуют. Если сервис токенов Spotify перестанет работать, создай приложение на developer.spotify.com (владельцу нужен Premium) и впиши `SPOTIFY_CLIENT_ID` / `SPOTIFY_CLIENT_SECRET`.

## Веб-панель

Панель слушает только `127.0.0.1:8090` на сервере, снаружи её не видно. Открывается через SSH-туннель:

- Windows: запусти `open-panel.cmd` из папки проекта.
- Любая система: `ssh -N -L 8090:127.0.0.1:8090 mcr`, затем открой http://localhost:8090.

Пароль хранится в `PANEL_PASSWORD` в `.env` на сервере.

Вкладки панели:

- **Плеер**: текущий трек, перемотка, громкость, поиск с подсказками, очередь (играть, поднять, опустить, убрать).
- **Настройки**: громкость, площадка по умолчанию, автоплей, 24/7 и его канал, канал мини-плеера, тайм-ауты выхода, лимиты, цвет плеера, вебхук мониторинга.
- **Статус**: бот, Lavalink, вход в YouTube, подключённые площадки и их проверка.
- **Логи**: последние 300 событий бота.

## Обслуживание

```bash
cd /opt/discord-music-bot
bash scripts/deploy.sh                 # обновить из git и пересобрать
docker compose logs -f bot             # логи бота
docker compose logs -f lavalink        # логи аудиосервера
docker compose restart bot             # перезапуск бота
tail -f /var/log/music-bot-update.log  # журнал автообновления плагинов
```

Версии плагинов Lavalink задаются в `.env` (`YOUTUBE_PLUGIN_VERSION`, `LAVASRC_VERSION`, `LAVALYRICS_VERSION`). Cron вызывает `scripts/update-plugins.sh` раз в час; если вышла новая версия и музыка не играет, скрипт обновит плагин и пришлёт уведомление.

## Разработка

```bash
cd bot
npm install
npm run typecheck
npm run build
```

Структура `bot/src`:

- `music/service.ts` — плеер, очередь, выход из пустого канала, 24/7, восстановление после перезапуска Lavalink.
- `music/autoplay.ts` — подбор похожих треков.
- `music/lyrics.ts` — тексты (LavaLyrics, LRCLIB).
- `ui/*` — мини-плеер, очередь, живой текст (Discord Components V2).
- `commands/*` — слэш-команды, автодополнение, кнопки.
- `web/server.ts`, `public/*` — веб-панель.
- `monitor.ts` — уведомления через вебхук.
